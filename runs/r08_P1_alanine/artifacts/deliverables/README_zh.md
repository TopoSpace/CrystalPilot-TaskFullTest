# 丙氨酸单晶：原始数据解析与精修结果

## 结论

从本次提供的原始衍射帧独立完成了指标化、积分、空间群判断、结构解析及精修。得到 **P2₁2₁2₁、Z=4 的丙氨酸 NH₃⁺/COO⁻ 两性离子结构**。结构几何、精修残差和数据完整度已接近常规小分子发表水平；但**绝对构型不能由这套数据确定，部分实验元数据仍缺失，因此不是无保留的投稿终稿**。

未读取其他运行、历史结构、评分目录或联网查询样品答案。未导入参考原子坐标。原始 inputs 保持只读，646 个原始帧的 SHA-256 在结束前全部核验未变。

## 处理中的关键发现

- 正式采集为六个扫描、616 帧；另外 30 个预实验帧未重复计入。
- DIALS 不依赖已知晶胞联合指标化。Bravais 几何、三组 2₁ 消光及 SHELXT 独立解共同支持 P2₁2₁2₁。
- 初始精修异常来自束挡/支撑阴影：某些等价反射在正常位置有数千计数，在受遮挡位置几乎为零，且周围原始背景同样衰减。
- 根据原始像素和探测器坐标加入保守掩膜后重新积分。相同骑乘氢模型的 R1 从 0.0600 降为 0.0301，wR2 从 0.2413 降为 0.0804，完整度不变。**未按 Fo−Fc 人工逐条删反射**；标准积分、partiality 和尺度化离群值过滤均有日志。
- 晶胞精修具有精确公共晶胞约束；用本地协方差展开补足 DIALS 在此情形下不输出 ESD 的限制，未改安装软件，原矩阵、方法和脚本均保留。

## 模型及可靠性

六个非氢原子各向异性精修，ADP 均正定。NH 省略差值图出现三个清楚峰；三个 N—H 的位置及 Uiso 独立、无约束精修，C—H 为骑乘模型。

关键键长：C—O 为 1.264(2)、1.246(2) Å，Cα—N 为 1.492(2) Å，两条 C—C 为 1.535(2)、1.520(2) Å。三个主要 N—H···O 氢键的 N···O 距离为 2.8410(19)、2.7987(19)、2.824(2) Å，角度约 166(2)、171(2)、162(2)°。

可靠性检查已经完成：

- 0.80 Å 截断和全部实测数据（延伸至约 0.708 Å）对照中，非氢原子最大位移分别为 0.00069、0.00091 Å；未因选择 0.77 Å 而改变结构结论。
- 独立按 CIF 坐标、ADP、IT92 散射因子和对称操作重算的 Fc 与交付 FCF 相符，振幅差异 R≈0.00069（包括 CIF 舍入）。
- 从 LIST 4 FCF 独立计算 R1=0.030218、wR2=0.073239、S=1.095429，与 SHELXL 一致。
- 在隔离目录仅使用交付 INS/HKL 复跑，重现最终精修指标。
- 本地 PLATON 的 CIF/FCF 数值检查一致。程序写出完整文本报告后未自行退出，被 45 秒超时终止；这一运行状态与原始报告均保留，**没有声称官方在线 checkCIF 通过**。

## 仍未解决的问题

1. **绝对构型未知。** 轻元素 Mo 数据的 Flack 与 Hooft 参数不够精确，不能指定 L/D 或 R/S，也不能据其数值宣称某个反演孪晶比例。文件中的手性方向只是一个任选手性解。
2. **实验信息缺口。** 可确认约 150 K、波长、帧数等，但晶体尺寸、可靠外形/颜色描述、绝对吸收透射因子、完整仪器/光学配置、样品来源及实验者信息未充分提供。没有把照片或晶面距离当作未经校准的尺寸事实。
3. **本地检查仍有警报。** 最终 PLATON：3 A、0 B、3 C、6 G。A 为缺少 Tmin/Tmax 与晶体外形；C 为缺少三维尺寸；G 涉及绝对结构不确定、体积 ESD 相关项、一个缺失高角反射及其他统计提示。逐项说明见 `validation/ALERT_RESPONSES.md`。
4. **系统误差范围。** 掩膜边界是基于本次原始像素的保守选择，不是厂家标定的遮挡图；仅使用相对经验多扫描尺度/吸收修正，未作面形解析吸收校正。统计 ESD 未涵盖所有可能的仪器系统误差。复核所需掩膜、像素证据和未掩膜对照均已保存。
