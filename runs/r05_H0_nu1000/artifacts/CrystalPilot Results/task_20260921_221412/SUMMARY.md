# NU-1000 框架解析与精修总结

## 结论与交付状态

从本轮 HKL 独立求解得到 P6/mmm 的三维 Zr-有机框架。框架重原子连接完整，
局部 Zr 配位与合成图中的芘基四羧酸配体相符；周期图经 Systre 识别为
(4,8)-连接 **csq** 网。没有使用参考结构或其他运行的坐标。

**状态为 diagnostic：框架已解析并收敛，但尚不能诚实宣称达到近发表级定稿。**
主要限制是数据合并质量、1.0 A 有效分辨率、孔道掩膜的更新不稳定、
节点质子化不明，以及实验元数据缺失。孔道溶剂和客体没有显式建模。
本目录的 CIF 使用完整 SHELXL ACTA 格式，不代表通过了发表级科学验证。

最终节点 `n0023`，模型修订 24，交付修订 5；
配对 SHELXL 作业 `job_20260921_225306`。
最后一次修改后进行了 `run_shelxl(mode="adopt", l_s=2)`，
随后 `write_outputs` 和对已写出 CIF 的 `run_checkcif`。

## 做了什么

1. 原 INS 只有重叠在原点的 C/H/N/O 占位记录，不作为结构使用。
   工具导入无原子起点，保留原始晶胞、波长和全部观测。
2. 在求解前分壳检查强度、CC1/2 和完整度，选用 1.0 A 截断。
   更高角度相关性趋近零或为负；没有因 R 值删除单独反射。
3. 显式声明并检验 P6/mmm；比较较低 Laue 对称性、系统消光和 SHELXT 结果。
   SHELXT 的中心对称解提供完整框架位置。非中心候选亦保留在原求解作业中，
   不把它们参数更多时较低的求解 R 值作为降群理由。
4. 将构成芳环的六个误标 O 改为 C。移除孔道中的 30 个碎片/重叠峰记录，
   依据为它们不属于连贯框架，含不合理短接触及孤立位点；不是以改善 R 为依据。
   原始解保存在 n0003。没有从模板凭空添加框架原子。
5. 保留两种独立 Zr、六种独立 O、十二种独立 C。
   O1/O2 为羧酸根 O；O3/O6 为簇内桥联 O；O4/O5 为显式末端 O。
   两个 Zr 位点均八配位，最终 Zr-O 约为 2.150–2.246 A。
6. 非氢原子各向异性精修；六个独立芳香 C-H 采用 AFIX 43、
   C-H=0.93 A、Uiso(H)=1.2Ueq(C)。C8 的自动 CH2 误判按芳环连接纠正为 CH。
   未虚构 O-H 或水分子取向。0.93 A 是计算约定，不是实测温度的证据。
7. 对弱数据下的芳香几何和 ADP 加入下述有限约束；权重通过 SHELXL 建议值迭代，
   最终 WGHT 0.1472 0，后续建议为 0.1471 0。
8. 仅以连续孔道掩膜处理非框架散射。固定 FAB 与未掩膜分支都可追溯；
   更新掩膜的不稳定已披露，不从其电子数反推客体数目。
9. FREE/EQIV 清除 SHELXL 半径表产生的非键 Zr···Zr 接触。
   最终键长表和以 Zr 为中心的角度表已读回检查，不含这些假配位项。
   这不删除原子、不约束距离，也不改变衍射观测。

## 每条 Restraint 的理由

六条声明在 SHELXL 中展开为 135 个 restraint 项，不是 135 条独立人工化学假设。
所有具体卡片均在 final.ins / final.res 中。

| 声明 | 对象与理由 |
|---|---|
| SADI 0.020 | 苯环 C2-C5-C3-C4-C8-C11 的六个相邻 C-C 键相近；不指定绝对键长。 |
| SADI 0.040 | 同一苯环六个 1,3 距离相近，限制弱数据引起的角度畸变。 |
| FLAT 0.02，C2 C5 C3 C4 C8 C11 | 苯环平面性，依据芳香配体图及已解连接关系。 |
| FLAT 0.02，C6 C7 C9 C10 C12 | 芘核独立原子部分的平面性；对称性生成其余部分。 |
| FLAT 0.02，O1 O2 C1 C4 | 羧酸根及其连接碳的局部 sp2 平面性；不固定芳环-芘核扭转角。 |
| RIGU 0.004 0.004，O1 O2 C1–C12 | 配体内键合原子的刚性键 ADP 相容性，稳定有限分辨率下的各向异性参数；不用于 Zr 或簇内/末端 O。 |

没有施加 Zr-O 距离、原子占有率或配体-金属比例约束。
C2-C5 与 C2-C11 的 SADI 偏差仍为 3.59 sigma，已检查且保留为问题，
没有放宽 sigma 或删除约束来消除警报。

## 框架与孔道

每胞有三组 Zr6 簇、六个 C44 配体。简化网含三个八连接簇节点、
六个四连接配体节点和 24 条边，构成单一三维 csq 网。
拓扑分析在 n0021 完成；后续节点仅修正输出连接卡并再收敛，
未改元素、占有率或框架连接。

最终框架的几何孔隙估计约 78.8%，沿 c 的通径约 28.4 A
（网格不确定度约 0.25 A，探针半径 1.2 A）。
这是空框架几何计算，不是气体吸附测量，也不是孔道无客体的证据。

实际参与最终精修的固定掩膜来自 n0013：体积 17360 A^3/胞、78.6%、
积分 343.6 e/胞，55 周期时收敛。后续重算失败或未收敛，
因此这个积分只能描述保存的计算快照，不能用于可靠的溶剂化学计量。
详见 VALIDATION.md。

## 仍未解决

- 有效分辨率和合并质量限制轻原子精度；C-C 平均标准不确定度约 0.012 A。
- 掩膜对后续模型/尺度变化不稳定，固定掩膜与最终模型不构成已验证的自洽迭代解。
- O-H 未定位；簇内氧/羟基及末端羟基/水的分配、可能的封端物均未知。
  C88 H44 O32 Zr6 只是显式原子模型式，不是完整电中性的实验化学式。
- Zr 位于吸收边附近，Sasaki 与 Henke 表值有差异；缺少能量标定和吸收资料。
- 局部 ADP 偏大、一个苯环等距偏差、末端 O 附近残余仍需进一步验证。
- 缺少衍射温度、仪器与晶体记录、吸收校正、晶胞不确定度、p4p 和原始帧。
  本轮无人工补充信息，所有未知值保持未知，没有代填。
