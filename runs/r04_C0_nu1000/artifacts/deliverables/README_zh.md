# NU-1000 框架结构解析与精修

## 结论

已从本轮强度数据独立求解并建立完整的 **P6/mmm 平均框架模型**，完成各向异性精修、连接性检查和处理参数敏感性测试。框架可复算，但数据质量及下述未决问题仍不足以支持“可直接投稿的无警报终稿”这一判断。

未读取其他运行或参考结构，也未联网检索该样品。只使用给定三项输入、现有软件及通用软件文档。`inputs` 内容未改变，交付 HKL 与原始 HKL 的 SHA-256 相同。

## 模型内容

- 20 个独立非氢位点：2 Zr、6 O、12 C，均采用满占有的各向异性平均模型；特殊位置的 SHELX 占有因子已正确计入。
- 每晶胞为 **3 个 Zr6 节点、6 个 C44O8 配体**；18 个 Zr 都是八配位。Zr–O 为 2.157–2.249 Å，羧基 C–O 为 1.245–1.269 Å。
- 配体上 6 个独立芳香氢为几何生成的 riding H，C–H 固定 0.93 Å；并非实验定位的氢。
- 坐标模型组成是每晶胞 C264H132O96Zr18，或 Z = 3 时 C88H44O32Zr6。**这不是完整样品的化学式**：未包括节点上未定的氢及孔道内容。CIF 的式量、密度和 F(000) 同样仅对应坐标模型。
- O3、O6 为节点三桥联氧；O4、O5 为端位配位氧。没有凭空添加节点氢或指定其 OH/H2O/调节剂归属。

初始 INS 只有重合于原点的占位原子且缺少 Zr。补充 Zr 后，SHELXT 独立定位节点与配体；按图中连接关系更正误分配的芳环元素，缺失羧基碳由最高差值峰补全。采用 DFIX/DANG/FLAT 与 RIGU/SIMU，具体目标值、标准差和原子列表全部在 INS 中。

## 孔道与稳定性

没有建立任何具体孔道溶剂或客体分子。仅用 `smtbx.masks.mask` 估计未指认的孔道散射，通过 **ABIN + 独立 FAB** 加到计算结构因子；观测 HKL 未改写。最终固定掩膜参数为 probe/shrink 1.3/1.3 Å，网格步长 0.25 Å，160×160×72，补全集开启，最多 100 轮。掩膜区域约 17381 Å³，占晶胞 78.67%。

未校正孔道的 1.2 Å 基线 R1 = 0.1824，已另行保存。不能把掩膜前后不同处理的 R 值当作独立的模型证实。

主要非氢坐标敏感性结果：

| 对照 | 最大坐标变化 |
|---|---|
| 1.2 Å 与 1.0 Å 截断 | 约 0.012 Å |
| 取消几何 restraints，保留 ADP restraints | 约 0.034 Å |
| 更保守的掩膜边界（shrink 1.0 Å） | 约 0.011 Å |
| Sasaki 改用 Henke 色散表 | 约 0.030 Å |
| 再一次掩膜/框架迭代 | 约 0.0045 Å |

还测试了孔道散射自由比例参数；未带来实质性框架改善，最终不采用。100 与 200 轮掩膜计算的实测反射系数差约为原系数 L1 范数的 0.11%，但电子数仍会变化。因此不以掩膜电子数认定客体种类、分子数或样品化学式。

## 尚未解决

1. **数据一致性偏差较大**，高分辨率信号弱；低角反射仍有系统性拟合偏差。没有原始衍射帧、积分/标度/吸收校正历史，无法追溯或修复来源。
2. 多个位移椭球偏大或偏长；SHELXL 提示 7 个位点可能需要 split。当前没有足够证据建立唯一的分裂模型，保留平均结构，而不把警报当成已确认的无序方式。
3. 节点氧的质子化、端位氧的准确化学归属及可能的局部无序/部分占有仍不确定。节点氢未定位。
4. 所给波长对 Zr 色散修正敏感。最终用 cctbx 的 Sasaki 表，Zr f′ = −9.0413504、f″ = 2.7716699；替代表测试已保留，但没有实验能量校准资料。
5. 孔道模型及几何 restraints 的不确定性未完整传播至坐标标准不确定度；未做独立 Rfree，不将敏感性对照称为交叉验证。
6. 衍射温度、晶体尺寸、晶胞标准不确定度等未提供。交付 CIF 已将软件自动填写的 293 K 改为 `?`。未完成正式 checkCIF/PLATON 验证，不声称已通过发表审查。

合成图仅给出：ZrCl4 35 mg、BA 1 g，DEF 3 mL，80 °C/110 min；图示配体 30 mg、DEF 2 mL；TFA 30 μL，120 °C/24 h。BA/DEF/TFA 的全称未在输入中明确，未据此补造信息。**合成温度不是衍射温度。**

## 文件与复算

- `nu1000_framework.cif`：校订后的主结构文件；`RES` 保留更多坐标小数位。
- 同名 `INS/RES/HKL/FAB/FCF/LST`：实际精修输入、收敛结构、原始观测、孔道贡献、计算结果及完整日志。**复算时不能遗漏 FAB。**
- `framework_overview.png`：由本轮解出的坐标绘制的框架、配体和节点。
- `calculations/`：未校正基线、掩膜输入/区域图、数据统计、敏感性结果、原始 SHELXL CIF 及 `computation_trace.zip`。原始 CIF 内的默认实验温度不应作为事实采用。
- `verification.json`、`input_integrity.json`、`manifest_sha256.json`：交付核验与文件校验值。
- `reproduce.ps1`：使用环境中给定的软件，在新目录重跑最终精修并重新校订、核验 CIF。
- `rebuild_mask.ps1`：从归档的零周期结构/FCF 重算掩膜。求解/精修脚本、主要中间轮次及保留的失败分支日志也在计算归档内；重复的原始 HKL 用归档清单指向同一份输入。

两份 PowerShell 脚本均已实际运行：精修统计在报告精度内完全重现；4395 行重建的 FAB 数值与最终所用文件完全相同。复跑日志与坐标差异检查见 `calculations/reproducibility_check.json` 及同目录的 `reproduced_*` 文件。

软件：SHELXT 2018/2；SHELXL 2019/3；给定 Python 环境中的 cctbx/smtbx、gemmi、NumPy/SciPy、Matplotlib。方法引用见各程序日志及 smtbx 源码中列出的 van der Sluis & Spek (1990), Acta Cryst. A46, 194–201。
