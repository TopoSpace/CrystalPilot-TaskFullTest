# 丙氨酸：自编算法解析与精修

## 结论

已由本次原始衍射帧得到与丙氨酸两性离子一致的完整结构。
最终结构的常规精修指标接近发表水平，但**尚不是经过独立晶体学软件验证的可直接投稿结果**。
绝对构型未知，所交付坐标的手性方向不能用于宣称 L 或 D。

## 主要文件

- `alanine.cif`：正式结构、坐标标准不确定度、各向异性位移参数、几何和限制说明。
- `alanine_reflections.fcf`：最终 623 个反射的 Fo²、σ、Fc² 和计算相位。
- `alanine_merged.hkl`：相同反射的定宽 `3I4,2F8.2` 文本；精确值以 CSV/FCF 为准。
- `alanine_molecule.xyz`、`alanine_unitcell.xyz`：分子和完整晶胞的笛卡尔坐标。
- `model_final.json`、`final_parameter_covariance.npy`：未舍入参数、统计量和完整协方差矩阵。
- `final_refinement_reflections.csv`、`merged_final.csv`：最终精修输入、权重和输出。
- `unmerged_absorption_all.csv`：包括遮挡标记在内的全部 3,895 个预测积分观测。
- `merged_corrected_observations.csv`：尺度、稳健权重、等价反射平均值，未隐去失强观测。
- `merged_corrected.csv`：保留至约 0.70 Å 的更高分辨率反射，未全部用于主精修。
- `validation.json`、`output_checks.json`、`cross_validation_reflections.csv`：检验结果。
- `METHODS.md`：算法、模型、输入来源及误差定义。
- `quality_diagnostics.png`、`molecule.png`：结果图。
- `frame_manifest.json`、`input_provenance.json`、`checksums.sha256`：输入和输出指纹。
- `*.py`、`*.log`、`reproduction_logs/`：本轮自行编写的源代码及计算记录。

`alanine_intermediate.cif`、带 `first`、`before` 的模型，以及没有 `final`
标记的早期精修文件均为检查点，不应误作最终结果。`cache/` 是可由原始帧重建的解码缓存。

## 复现

在任务根目录使用 `environment.json` 唯一指定的解释器，不安装任何依赖：

```powershell
$py = (Get-Content -LiteralPath .\environment.json -Raw -Encoding UTF8 | ConvertFrom-Json).environment.python
& $py .\deliverables\reproduce.py --check-only
& $py .\deliverables\reproduce.py --refine-only
& $py .\deliverables\reproduce.py --full
```

三条命令分别为输出自检、从保存的六原子初始模型重新精修、从正式原始帧重跑全部流程。
每条命令单独运行即可，不要求顺次全部执行。重跑会更新 `deliverables` 内的计算输出；
不会写入 `inputs`。完整流程使用固定随机种子，但数值平局可能选择等价原点或反向手性；
应比较结构因子和统计量，不要求坐标文本逐字一致。

## 尚未解决

1. **绝对构型不能确定。** Friedel 对已合并，未精修 Flack/Hooft 参数，未使用反常散射项。
2. **晶胞存在外部标定不确定性。** 自拟合晶胞与附件既有晶胞相差约 0.06–0.09%。
   已做逐扫描留出稳定性检查，但像素尺寸、波长谱和仪器系统误差尚未独立核准。
   CIF 中的标准不确定度是内部估计，不能涵盖这一全部系统误差。
3. **没有外部 checkCIF 或独立程序复核。** 自编文件解析、结构因子重算、
   正定位移参数、几何、差值图和留出检验均通过，但不等同于正式数据库验证。
4. **数据还原仍有近似。** 使用圆形求和积分、背景遮挡掩膜、等价反射稳健合并；
   68 个背景判断为遮挡的观测被排除，另有 51 个观测得到较低稳健权重。
   最终分辨率范围内未额外过滤的合并 Rint 约 6.76%；稳健筛选诊断约 4.07%。
   没有根据 Fo/Fc 残差删除独立反射。所有观测及标记均已保存。
5. **吸收和照明模型有限。** 数值校正采用输入九晶面和输入 μ=0.11620 mm⁻¹，
   假设均匀照明，T=0.98926–0.99540；未独立重新测量晶形或束斑。
6. **高分辨率覆盖不足。** 至 0.70 Å 的覆盖约 82.4%，故主精修截至 0.75 Å。
   仍缺少的 19 个允许独立反射不能由计算补造。
