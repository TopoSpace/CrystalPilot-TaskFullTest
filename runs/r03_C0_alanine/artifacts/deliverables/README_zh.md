# 丙氨酸单晶结构解析与精修

本次结果仅来自给定原始数据和所供软件，未使用外部参考结构或样品答案。计算日期：2026-09-21。

## 结论

已从 616 张正式衍射帧独立完成索引、积分、定标、结构解析与全矩阵精修，得到空间群 **P2₁2₁2₁（No. 19）、Z = 4** 的丙氨酸两性离子结构。非氢原子各向异性精修，7 个氢均由差值图定位并独立精修坐标及 Uiso，无几何约束、无 restraint。

几何、R 值及残余电子密度已接近常规小分子发表质量，但**不是已经完成发表验证的结构**：绝对构型未确定，部分实验元数据缺失，完整 checkCIF/PLATON 验证尚未完成。

## 数据处理与关键判断

1. 使用六个正式扫描，帧数为 92、92、150、58、116、108；30 张预实验帧未混入正式数据。为满足文件模板导入而制作了零填充命名的逐字节相同副本。原始 `inputs` 未写入；全部 616 张正式帧在交付前重新通过 SHA-256 校验。
2. DIALS 3.30 从 P1/FFT1D 联合索引开始，未以输入文件的既有晶胞估计作为目标。Bravais 分析、三个轴向螺旋消光与 SHELXT 解共同支持正交 P2₁2₁2₁。未采用一次 `small_molecule=True` 对称性试算的有歧义排序结果。
3. 初始积分暴露了严重的局部遮挡：等价的 |hkl| = (2,1,4) 在部分帧中落入 beamstop 阴影，几乎只记录到背景。直接定标会产生伪异常散射信号及错误强度合并。检查的是本次原始帧，而非参考图片。
4. 从六组原始帧背景图辨认 beamstop 与支架阴影，按两种几何设置定义保守像素掩膜，再重新积分。掩膜、坐标、背景图和具体反射的原始像素裁剪全部保留。没有用逐条手工 `OMIT` 代替遮挡处理。
5. 最终采用 DIALS physical 时间尺度模型，间隔 30°；不加衰减项、吸收谐函数项或基于晶体外形的吸收校正。低阶吸收模型试算未提供足以采用额外参数的明显改进。保留 DIALS 自动异常值及 partiality 筛选，并保留 Friedel 对。
6. 按高角度覆盖情况选主模型 d ≥ 0.76 Å：完整度至约 0.80 Å 为 100%，此后逐渐降低，0.76 Å 以外各壳层降至约 70%、39%、41%、21%。截断不是以降低精修 R 值为目标；所有更高角度可用反射另存并完成对照精修。
7. SHELXT-2018/2 独立定位全部六个非氢原子。SHELXL-2019/3 各向异性精修后由差值图补入七个氢；独立精修，不使用 riding H。最终固定权重为 a = 0.0337、b = 0.0755。
8. 消光项试算 EXTI = 0.014(9)，不足 2σ，因此不保留。没有加入无序或孪晶模型；当前差值图未显示需要它们的明显证据，这不等于完全排除细微无序或孪晶。

## 仍未解决

1. **绝对构型未知。** Mo Kα 下该轻原子样品的异常散射信息不足；Flack 参数不具判别力。交付坐标的手性取向仅为解结构得到的任意一手，不能据此声称 L、D、R 或 S。需独立手性证据，或足够异常散射信号的新实验。
2. **完整验证未完成。** 所供 Windows PLATON 调用进入错误对话框，报 “No Filename Extension Found on Filename”，未生成有效 ADDSYM/checkCIF 报告；相关命令记录、错误窗口截图已保留，进程已结束。现有程序化检查不等价于 IUCr checkCIF，尚不能声称没有 A/B alerts。
3. **实验信息不全。** 晶体尺寸、颜色、习性、制备过程、光学配置、温度校准不确定度及操作者等未能可靠建立；CIF 保持未知，不由照片猜测。未向任何在线服务上传数据。
4. **温度记录不一致。** 参数文件为 149 K，而实际采集日志的样品监测为 149.93–150.05 K，故主 CIF 报 150 K。SHELXL 自动给出的 150(2) 中“(2)”不是本次实测不确定度，已去除；原始生成 CIF 另存。
5. **系统误差仍可复查。** 没有可靠晶体尺寸用于外形吸收校正；像素掩膜虽有原图依据，仍是人工几何定义。低角度 (1,0,2) 的观测/计算差异较明显，只有一次有效观测，原因未确定，未人为删掉。发表前宜复查此类低角度数据和仪器几何校准。

## 文件说明

- `alanine.cif`：主交付结构，补充了有输入依据的元数据；内嵌 SHELXL 结构与强度记录。
- `alanine.ins / .hkl / .res / .fcf / .lst`：可直接复算的主模型输入、结果、结构因子和完整精修列表。
- `alanine_shelxl_raw.cif`：未经元数据整理的 SHELXL 原始 CIF，便于核对；不是第二套模型。
- `reports/cif_metadata_changes.json`：逐项元数据整理记录，未更改坐标、ADP、反射或 R 值。
- `reports/alanine_adp50.png / .pdf`：由主模型生成的 50% 非氢位移椭球图；H 使用固定显示半径。
- `processing/`：最终定标的 EXPT/REFL、未合并 MTZ、定标报告、掩膜与逐帧哈希清单。DIALS 文件中的原始路径指向本工作区。
- `sensitivity_all_resolution/`：全分辨率对照模型及其输入输出，未整理实验元数据。
- `replay_verified/`：最终精修的独立复算记录；其中自动生成 CIF 未做元数据整理，主交付仍是顶层 `alanine.cif`。
- `calculation_records.zip`：本次 `scripts/` 和 `work/` 计算记录、成功及失败试算、掩膜、诊断图和计算中间文件；不重复打包 616 张工作副本，也不包含软件。
- `reports/command_index.json`：全部已记录命令；`selected_raw_pipeline=true` 标出主流程。失败试算未被隐藏，程序退出码为零也不自动等价于成功精修。
- `reports/sha256_manifest.json`：交付文件哈希。

## 复现

仅复算最终精修，在当前工作区 PowerShell 执行：

```powershell
.\deliverables\reproduce_final.ps1
```

从原始帧重跑已采用的处理流程，在当前工作区执行：

```powershell
C:\users\<user>\miniforge3\envs\dials\python.exe scripts\replay_pipeline.py replay_raw
```

`replay_raw` 必须不存在。脚本只在本工作区新建目录，复制本次 inputs 与脚本，再按命令记录重跑；不会改写给定 inputs 或现有结果。需要 `environment.json` 所列软件仍在原位置，且 DIALS 的 Scripts、Library/bin 已在 PATH。若仅使用 ZIP，先在新的工作目录解包，并提供同一份 `inputs/`。重跑输出的 CIF 是 SHELXL 原始版本；主交付 CIF 的元数据整理见 `package_results.py` 与逐项记录。
