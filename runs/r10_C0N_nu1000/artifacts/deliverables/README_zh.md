## 数据检查

读取 337,815 条非零指数、正标准差观测，按输入对称性和反演合并为 11,289 个独立反射。逆方差合并；当等价观测的离散超出给定误差时放大合并误差，不把误差缩小到内部统计值以下。

- 观测分辨率范围：0.69108–14.91916 Å；`I > 2σ(I)` 的独立反射 2,104 个。
- 全范围完整度约 88.16%，主要缺失在最高分辨率区；1.0–3.0 Å 范围基本完整。
- 全数据 Rint = 0.6298；该总体值受大量高角噪声影响。2–3 Å、3–5 Å 的 Rint 分别约 0.194、0.115。
- 随机半数据相关 CC1/2：1.0–1.1 Å 为 0.543；0.9–1.0 Å 为 0.237；0.8–0.9 Å 和 0.691–0.8 Å 为负。不能把 0.691 Å 当作具有可靠原子信息的有效分辨率。
- 最低角的 001、100、2 -1 0、200 没有观测。没有补造其强度，也没有将它们置零参与精修。
- 主模型仍使用全部合并反射，包括负强度，未用 `I > 2σ` 筛选精修数据。

完整统计见 `data_statistics.json` 和 `resolution_audit.json`。

## 结构与算法

所有算法均为本轮新编写的 Python 代码，依赖仅为标准库、NumPy、SciPy 和 Matplotlib。

1. 由 INS 的线性表达式构造 24 个空间群操作，验证群闭合和晶胞度量不变性。
2. 从实测强度计算 Patterson 图；检验由重原子矢量提出的 Zr 特殊位置假设。两类独立 Zr 位点分别生成 12 和 6 个晶胞内 Zr。
3. 用重原子相位计算傅里叶图，识别节点氧和连续芳环；按图示配体连接补入有化学连接支持的羧基碳，再对全部框架位置精修。没有导入其他 NU-1000 坐标。
4. 在特殊位置允许的坐标子空间及对称性允许的位移张量空间内，直接对强度最小二乘；结构因子和参数导数均为自行实现。
5. 先各向同性，再各向异性。采用芳香/羧基距离、1,3 距离、平面、刚性键位移和弱相邻位移相似性 restraints。具体目标、标准差、权重和计数在 `restraints.py`、计算日志中完全展开。
6. 六类芳香骑乘氢共生成 132 个晶胞内 H，C–H = 0.95 Å，Uiso(H) = 1.2 Ueq(C)，在宏循环间更新。不是从密度图独立定位的氢。

主模型有 20 个独立非氢位点（2 Zr、6 O、12 C），另有 6 类计算氢；156 个独立精修参数，306 个数值 restraint 方程。后者包含对称相关的重复约束，不能当成 306 个独立实验观测。

周期图检查得到：

- 每晶胞 3 个 Zr6 节点、6 个完整 C44O8 配体；节点内非配体部分为每节点 Zr6O16。
- 每个 Zr 八配位；每个节点连接 8 个配体，每个配体连接 4 个节点。
- 一个贯通周期边界的三维连通框架，周期闭合平移秩为 3。
- Zr–O 2.134–2.275 Å；羧基 C–O 1.255–1.267 Å；C–C 1.343–1.496 Å。
- 所有非氢位移张量均为正定。

模型晶胞内容为 C264 H132 O96 Zr18；这**不是完整样品化学式**，没有包括节点质子和孔道物种。没有据此伪造电荷平衡、分子量、密度或样品 Z 值。

权重为 `w = 1 / [σ(I)^2 + (0.08P)^2]`，`P = [max(I,0) + 2Ic] / 3`。日志另列仅用测量 σ 的 `wr2_sigma`，不要与表中实际精修权重的 wR2 混用。R1 对负实测强度采用 `Fo = sqrt(max(I,0))`；负强度仍原样参与强度精修。

主模型 1.2 Å 截断的未扣除差值图最大/最小约 +1.694 / −1.472 e/Å³。未观测项和 F000 在图计算中置零，不代表测到了零强度。

10% 分层留出精修检查使用 1,120 个留出反射，其中 224 个满足 `I > 2σ`；留出 R1 约 0.1956，工作集约 0.1979。初始结构识别已使用全数据，这只是精修稳定性检查，**不是从开始就隔离的盲测**。

## 尚未解决

1. **残差仍高。** 低角区不能由目前的纯框架模型充分解释。未建模孔道密度与这种现象相容，但尺度、散射模型和实验系统误差也无法仅凭当前输入排除。
2. **色散模型未获得独立物理校准。** 显式中性原子四高斯近似存于 `scattering_constants.json`。主模型另拟合 Zr 的统一有效实部偏移，约 −9.559(229) e；它只是拟合参数，不是查表值或已验证的异常散射因子。虚部取零，尚未校准。零偏移对照的非氢坐标最多改变约 0.053 Å，位移参数的变化更明显。
3. **部分轻原子存在模型依赖。** 改用 1.0–3.0 Å 精修时，非氢坐标变化 RMS 约 0.037 Å、最大约 0.077 Å。CIF 中的条件标准不确定度不包含这类系统误差，也不包含未知的晶胞误差。
4. **节点质子及端基身份未定。** O1/O6 是仅连接一个 Zr 的端位氧；O2/O3 是三桥联氧。不能据此唯一分配 O、OH、H2O 或配位溶剂的质子状态。芳香氢以外的 H 未补造。
5. **未采用孔道扣除。** 自编柔性密度投影虽降低工作集残差，却恶化留出低角反射，例如初次试验留出 R1 约从 0.342 增至 0.678；更受限的孔道模型也未提供有说服力的留出改善。这些试验明确被拒绝，未用于主 CIF 或 FCF。试验中的“电子数”不能当作样品溶剂含量。
6. **不是标准发表验证。** 本轮仅对给定空间群工作模型作检验，没有穷举降对称、无序、孪晶、吸收或消光模型；没有调用任何现成验证程序或外部服务。不能把自检通过解释为通过正式结构验证。
7. **骑乘氢导数采用近似。** 氢在宏循环间按母原子几何更新，在内循环中视为固定散射贡献，没有传播骑乘位置对母原子的链式导数。解析导数自检覆盖非氢独立参数模型；包含氢时的精修及条件不确定度还带有这一近似。

因此，本轮交付是可继续研究、可复算的完整暂定框架；“临近发表级精修”的目标未完成。
