# NU-1000 结果简要说明

**已解出并交付可复现的框架模型，但尚未达到可直接发表的最终精修质量。**

主结构：`nu1000_framework.cif`；完整说明：`README_ZH.md`；便携包：`nu1000_framework_bundle.zip`。

- 空间群 **P6/mmm（No.191）**；a=b=39.1900 Å，c=16.6100 Å，γ=120°。
- 晶胞含 **3 个 Zr6 节点、6 个 C44O8 配体**；三维连通，所有 Zr 八配位。
- 非氢模型 Zr18 C264 O96，另有 132 个理想化芳香骑乘 H。节点质子未定，该原子库存不是完整实际化学式。
- 原始 337815 条观测合并为 11289 个独立反射。主精修用 14.919–1.0 Å 内全部 **4395** 个强度，包括弱/负值；无低角删减，无孔道原子或孔道密度校正。
- **R1(I>2σ)=0.1750，R1(all)=0.2638，wR2=0.4629，GoF=2.51**。差值密度 +1.87/−1.29 e Å⁻³。不能用中高角子集较低的 R 值代替以上结果。
- 自编几何、对称性、导数及独立 CIF 结构因子回算检查通过。检查点精修精确复现；从原始输入完整复跑也得到相同框架和几乎相同指标。

**未解决：**低角额外散射；Zr 有效散射修正与其他参数的相关性；部分较大的轻原子热参数及较强几何约束；节点 O/OH/H2O、占位/缺陷和质子化；采集温度、吸收校正、晶胞标准不确定度等缺失实验信息。未采用未可靠验证的孔道密度试算，也未声称通过现成晶体学软件验证。

代码、完整反射表、精确模型、形式标准不确定度、计算日志、原始输入哈希及复现命令均已保存。本轮只使用指定通用 Python 环境和自行编写的晶体学算法，没有使用禁止的软件、库、参考结构或网络资源。
