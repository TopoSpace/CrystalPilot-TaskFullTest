# NU-1000 框架解析与精修交付

## 结论与使用边界

**已独立解出并精修可检查的 NU-1000 非氢框架；尚未达到可直接发表、验证完整的最终精修质量。**

主结构文件是 **`nu1000_framework.cif`**，不是 `framework_initial.cif`，也不是任何 `density`、`pore` 或 `chargeflip` 试算。最终主模型不含孔道溶剂/客体原子，也**没有采用孔道电子密度校正**。框架组成、连接和原子配位得到数据与几何检查支持；但低角错配、有效 Zr 散射修正的相关性、较大的轻原子热参数尚未解决。不能用截去低角后的 R 值代表完整精修。

本轮仅使用给定 Python 3.12 环境、Python 标准库及 numpy/scipy；所有晶体学读取、对称运算、合并、Patterson/Fourier 求解、精修及验证算法均在本轮编写。没有运行晶体学软件、读取既有晶体学程序源码、访问参考结构/其他任务目录、联网或安装软件。输入只读。

## 晶胞、空间群与框架

- 空间群：**P 6/m m m（No.191；Hall -P 6 2）**。
- a = b = **39.1900 Å**，c = **16.6100 Å**；α = β = 90°，γ = 120°；V = **22092.8015 Å³**。
- 波长 **0.68883 Å**。晶胞、波长取自 `start.ins`；晶胞标准不确定度未知。
- 非对称单元：**2 Zr、6 O、12 C**，另有 **6 个理想化芳香 H 位点**。
- 晶胞非氢内容：**Zr18 C264 O96**；包括 **3 个 Zr6 节点、6 个 C44O8 配体**，共 378 个非氢原子。
- 骑乘芳香 H 为每晶胞 132 个，模型总数 510。**C264 H132 O96 Zr18 仅是模型原子库存，不是完整实测化学式**：节点质子和孔道内容未指定。
- 两类 Zr 均八配位；Zr—O = **2.1271–2.2635 Å**。O2/O3 是三连接节点氧位点，O4/O6 是羧酸根氧，O1/O5 为端位氧；不能仅凭本数据把这些位置逐一指定为 O²⁻、OH⁻ 或 H2O。
- 芳香 C—C = **1.3763–1.4433 Å**；芘—苯连接 1.5021 Å，芳基—羧基连接 1.4731 Å；C—O = **1.2624–1.2667 Å**。
- 苯/外接键、羧基、芘平面的 RMS 偏差分别约 0.0102、0.0083、0.0040 Å。几何受约束，不能将这些平整度当作完全独立的数据证据。
- 配位/共价图的周期平移循环秩为 **3**，确认三维网络。所有最终 ADP 正定，特征值范围约 **0.0557–0.2786 Å²**；部分数值仍偏大。

## 输入的含义

`start.ins` 只有原点占位原子，其 SFAC 甚至不含 Zr；这些占位原子及 UNIT/ZERR 内容没有被当作已知化学式或已解结构。由输入的 11 条 SYMM、恒等及 LATT 的反演生成 24 个操作。强等价反射相关约 0.985–0.989，支持 P6/mmm；这不是声称已经穷尽所有低对称或无序替代模型。

直接查看了提供的 `synthesis.png` 原图：ZrCl4 35 mg、BA 1 g、DEF 3 mL，80 °C/110 min；配体 30 mg、DEF 2 mL，TFA 30 μL；120 °C/24 h。BA 等缩写按原图保留。配体图支持四羧基芳基芘骨架，与求得的 C44O8 非氢配体一致。**这些温度是合成条件，不是衍射采集温度。**

已有输入是积分强度 HKL，并无原始衍射帧，所以本轮无法重新做图像积分、独立指标化、吸收校正或衍射图像层面的伪影检查。

## 数据与精修指标

- 原始观测 **337815** 条，P6/mmm 合并后 **11289** 个独立反射，平均冗余约 29.92。
- 约 41.95% 原始强度为负；没有把负强度强行删掉。等价观测使用等权平均，σ 取传播计数误差与内部离散度标准误的较大值。初期逆方差合并只保留作诊断。
- 名义最高分辨率 0.6911 Å，完整名义范围覆盖率约 88.16%；到 1.0 Å 覆盖率 **4395/4401 = 99.864%**。
- 1.1–1.0 Å 壳层 CC1/2 = 0.490；1.0–0.9 Å 为 0.196；0.9–0.8 Å 为 -0.028，更高角多数无可靠信号。因此选择 **1.0 Å** 主精修截止，不把名义 0.69 Å 当作有效结构精度。
- 主模型使用实测 **14.919–1.0 Å** 内全部 4395 个独立强度，包括弱/负值；无针对某些反射的离群删除，也没有低角剔除。
- 到 1.0 Å 的总体等权中心 Rint = 0.426。它包含大量弱/负观测；应结合分壳层及强等价反射检验阅读，不能只用较好的强反射一致性掩盖总体数据噪声。

差值图为 1.0 Å 截止、F000=0 的复数差值系数实部投影，负 I 在制图时令 Fo=0；不是经孔道校正或溶剂消除后的图。最大正峰距最近框架原子约 3.82 Å，在孔道区域，但这不足以指定任何客体分子或确认所有残差都来自溶剂。

权重：`w = 1/[σ(I)² + (0.08P)² + 0.01]`，`P = [max(I,0)+2Ic]/3`，迭代更新。最终统计由最终计算值重算。**旧中间 JSON 中 `metrics_*['wR2']` 使用另一套诊断权重（0.05 Iobs），不等于表中实际权重 wR2。以 `final_statistics.json` 为准。**

如将主模型回算到全部 11289 个名义分辨率反射，R1(obs)=0.19731，R1(all)=0.47804；这个范围未全部参与拟合。只看主模型的 3–1 Å 子集，R1(obs)=0.12462；另一个仅拟合 3–1 Å 的模型约 0.12379。**这两种中高角指标均不是全范围精修结果。**

## 求解与约束方法

1. 自编固定列 HKLF4 读取、空间群操作、对称合并、覆盖率和随机半数据相关计算。
2. Patterson 与多个 Zr6 取向/随机起点检验，确定两个独立 Zr 位点；没有使用参考坐标。
3. 重原子相位的差值 Fourier 峰给出 6 O 与 12 C 独立位点；按实际连接检验元素分配及完整芘/苯/羧酸根骨架。
4. 从各向同性模型开始，使用位点对称性允许的坐标和 Cartesian 各向异性张量参数；自编 F² 最小二乘和解析结构因子导数。
5. 加入通用化学几何约束：苯 C—C 1.395 Å（有效 σ 0.00625 Å）、其他芳香 C—C 1.41 Å（0.010 Å）、芘—苯连接 1.49 Å（0.00875 Å）、芳基—羧基 1.49 Å（0.0075 Å）、C—O 1.26 Å（0.00625 Å）；sp²/羧基角与平面约束，最终 `geometry_strength=4`。最终几何明显依赖这些约束。
6. 相邻轻原子 ADP 相似性 σ=0.06 Å²、沿键刚性差 σ=0.008 Å²。188 个几何/ADP residual rows（不是 188 个独立观测），另有 60 个最终不活动的正定性下限惩罚行；原计算报告总计 248 行，CIF 的 restraint 数采用 188。
7. 芳香 H 按 C—H=0.95 Å，Uiso(H)=1.2Ueq(C) 骑乘，不独立精修；未添加节点 H。精确使用过的 H 坐标保存在 JSON 中，以避免重新生成方向造成复算细微差异。
8. 占位固定为 1。没有证明不存在缺陷或部分占位。

中性原子散射用代码中列明的四高斯解析近似。鉴于给定波长接近 Zr 吸收边，同时拟合了**经验有效** Zr 实/虚部项：f′≈−9.732，f″≈6.235；形式标准不确定度约 0.35/0.37。它们不是独立校准的物理异常散射因子；与尺度、ADP、未建模散射有相关性，不能移用于其他波长或实验。C/H/O 的异常项近似为零。

## 检验和未采用的试算

- 24 操作群闭合、晶胞度量保持、全晶胞复数求和与简化模型一致性、对称强度不变性和解析导数均经过自编数值检查。
- 独立 CIF 读取后，展开原子库存和多重度符合预期；CIF 回算 F² 与保存 FCF 的相对 L2 差约 **9.9×10⁻⁸**，带 H 的解析导数有限差分最大相对误差约 **2.0×10⁻⁷**。
- 从保存的 `framework_conservative_cv` 检查点重跑最终精修，坐标和计算强度差均为 **0**（当前环境）。见 `reproduction_comparison.json`。这些检查证明代码/文件一致，不证明模型已完整或实验无误。
- 固定 7% 反射留出诊断：work 4086、test 309；强反射分别 1891/138。`framework_conservative_cv` 的 R1(obs) work/test = **0.17590/0.16631**。初始求解曾使用所有数据，因此这**不是完全盲测的 Rfree**。最终主模型已用全部 4395 反射精修，其 `metrics_test` 不再是留出预测。
- 14 分量连续孔道密度试算将 work R1 降至约 0.122，却使 test 达约 0.177；没有采用。6 分量的某种孔道边界选择得到 work/test≈0.142/0.160，但改善有限、边界敏感、电子数不稳定，也未采用。
- 实空间正性/孔道支持、低角相位修复及电荷翻转有训练改善但不稳定或留出误差变差，全部保留为失败/探索记录，不用于主 CIF，不把试算电子数当作实测溶剂含量。
- 中高角/全角处理比较，Zr 坐标变化约 0.001–0.004 Å，部分 O/C 变化可达约 0.06 Å，提示轻原子模型误差大于单纯形式协方差可能反映的范围。

## 尚未解决的问题

1. **低角额外散射未可靠解释**；不能保证全部都是孔道溶剂，也可能有吸收/尺度误差、缺陷或无序贡献。无被验证接受的孔道校正。
2. **节点 O/OH/H2O 分配与节点 H 未定**，端位氧化学性质和实际占位、完整电荷平衡、缺陷浓度未定。CIF 中完整化学式、式量、Z 等留为未知，不编造密度或完整 F000。
3. **有效 Zr 散射项未经独立校准**；大 ADP 和较强几何约束限制了轻原子精度解释。
4. **实验元数据缺失**：采集温度、晶体尺寸、仪器、吸收校正方法、晶胞标准不确定度未知。
5. 未使用且未声称通过 checkCIF、PLATON 或其他被禁止的现成验证程序；仅有本轮自编检查。
6. **临近发表级的完整精修目标尚未达到。** 当前交付适合审查已解框架、复现计算和继续改进，不宜不经进一步工作直接提交为最终晶体学精修。

从原始输入完整重建：

```powershell
& $py 'deliverables\reproduce.py' --mode from-inputs
```
