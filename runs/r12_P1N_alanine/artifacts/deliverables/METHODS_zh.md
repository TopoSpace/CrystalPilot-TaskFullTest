# 自编算法、假设与数据溯源

本轮只使用 `environment.json` 指定的 Python 3.12 环境、Python 标准库、NumPy 和 SciPy；未调用任何晶体学程序或程序库，未安装、下载或联网检索。没有读取外部参考结构。所有实验信息来自本次 `inputs/alanine/`。本文件描述的是算法，不代替独立的标准晶体学验证。

## 1. 实验输入与解码

- 正式测量为6批、616张 `pgw240033_Mo_[1-6]_*.rodhypix`，每帧0.5°、2 s。另30张预实验帧不计入正式还原。
- 每帧采用自身二进制头中的 omega、theta、kappa、phi，不根据文件名猜测角度；部分负向扫描的编号与采集日志的时间顺序不同。
- Mo Kα平均波长0.71073 Å，采集日志温度约149.93–150.05 K，结构报告150 K。晶体尺寸、颜色、形状等未确证信息保留为未知。
- `raw_frames.py` 独立解释 TY6 差分压缩：每行首个literal、49个16像素打包块及15个尾部literal；两个nibble分别表示8像素半块的位宽；8位块的int16/int32溢出值位于整个块之后。逐行累加差分得到800×775计数。
- 全部616帧逐一检查压缩字节消费长度、int16/int32溢出数和像素下界。`frame_metadata.json` 保存原始帧SHA-256。
- `test_algorithms.py` 以独立的简易合成编码器测试全部1–8位宽和两种溢出类型，并验证原始帧哈希未改变。这是自测，不是第三方格式认证。

## 2. 晶格和探测器几何

初始晶胞及带波长尺度的UB取自本次输入的 `expinfo/*crystal.ini` / 自动晶胞报告，而不是外部已知丙氨酸结构。因此这是**输入晶格的独立指标确认与重新校准**，不是宣称完全无先验的从零晶胞搜索。

- `geometry_probe.py` 枚举像素坐标符号、探测器角度、κ倾轴方向及马达旋转符号，以观测强峰的整数指标符合度确定约定。
- `geometry.py` 使用双平面模块模型、0.1 mm像素、约±19°模块倾角；联合拟合3个正交晶胞长度、每批3个取向角、每模块6个位置/取向参数，共33个参数。
- 用强度加权峰组质心校准。1422组中1组几何残差超过预设阈值，最后使用1421组；保留全部残差和被排除记录。
- `validate_geometry.py` 给出满秩线性化协方差和20%留出峰预测。晶胞su仅为条件统计不确定度，不包含波长、探测器模型及相关质心误差等系统项。

## 3. 反射预测、积分与遮挡

定义无量纲倒易向量 `v = UB h`，旋转后 `g = Rz(-omega) v`，入射方向为 `(1,0,0)`。Ewald条件为：

```
vx cos(omega) + vy sin(omega) = -|v|²/2
```

求两个根并与扫描角域、模块平面和探测器边缘相交，预测至名义分辨率0.70 Å。

主积分设置：

- 像素孔径半径4.5；背景环半径7–10。
- 使用背景均值，不用低计数图的零中位数；两次排除明显邻近峰污染的背景像素。
- 每帧净计数为 `raw - Nsignal * background_mean`，保留负值。
- 计数方差包括信号区域和背景均值估计项；背景为零时使用0.01计数的小方差下限。
- 摇摆半窗（度）：

```
max(1.25, min(10, 0.25 + 3.5*sqrt(0.07² + (0.10*|g|/max(|g_y|,0.01))²)))
```

- 所有纳入角窗的帧在预测中心使用固定xy孔径；未做三维profile拟合。扫描端点截断、孔径接近模块边缘以及 `|g_y| <= 0.025` 的观测不进入合并。
- Lorentz校正乘 `|g_y|`；极化校正除 `(1+s_x²)/2`，其中 `s=g+(1,0,0)`。共同的帧宽/曝光常数并入总比例因子；未假装已知真实入射偏振状态。

`audit_pixels.py` 从原始帧的“像素是否有计数”占有率建立每批静态掩膜：5×5均值低于0.005，或低于局部81×81均值的45%，再膨胀6像素。该掩膜针对完整或部分遮挡，不使用计算结构因子。不能排除仍有动态遮挡漏检。

`run_sensitivity.py` 分别以1.75°最小半窗、6像素孔径独立重积分。主模型并非按最低R因子挑选：更大孔径略改变R值但没有显著改变坐标，仍保留4.5像素、1.25°主设置。

## 4. 对称合并与误差

- Laue `mmm`，按 `abs(h,k,l)` 合并，包含Friedel等价；无法据此确定绝对构型。
- 只利用等价反射交替求运行批次和模块比例因子，run1/module0为基准。
- 初值用组中位数；比例拟合使用soft-L1。信号的Poisson方差由等价组期望强度估计，而不是逐个观测本身的低计数值，避免低计数观测获得不合理高权重。
- 最终观测权重包含4%组强度误差项；组内散布超过计数误差时增大合并标准误。
- 异常规则：至少3个等价、组中位数SNR>5、偏离组中位数超过 `max(8sigma, 30%组中位数)`；只基于对称等价，不基于原子模型。若规则把同一组全部标为异常，则保留整组并放大误差，不任意选择模式。
- `observed.hkl` 是本程序写出的通用h k l I sigma文本，**并不表示调用了任何SHELX程序**。
- `merged_all.csv` 还包括17个轴向奇数消光反射；它们不进入P212121结构精修。其强度与背景相容。
- `observation_flags.csv` 对全部预测记录给出位标记：1扫描端点、2少于2帧、4低Lorentz、8背景阴影、16无效数值、32对称异常。对应原始完整观测见 `unmerged_integrated.csv`；各类排除可重叠。

没有使用物理吸收校正、高阶多扫描吸收拟合、消光校正或反常散射校正。run/module比例校正不能替代这些物理过程。

## 5. 结构求解和精修

- 早期在较差的合并数据上运行的电荷翻转没有收敛。`solution.json`、`solution_density.npy`、`solution_trials.json` 是失败探索记录，**不是最终结构**。
- 有效求解使用 `search_molecule.py`：通用丙氨酸连接关系、理想四面体/三角平面键几何、3平移+3旋转+1羧基扭转角的差分进化。没有读取参考分子或晶体坐标。
- 最终代码至少比较两个随机起点。C与N只有一个电子的差别，首次完整重现曾落入N/甲基碳指认混淆的局部极小值；`refine.py` 现显式比较两种指认，以实测F²目标选取，记录在 `assignment_trials.json`。
- 先各向同性非氢，再加入骑乘氢，最后全部非氢xyz及各向异性U自由精修。没有非氢键长/键角restraint。
- U用Cholesky矩阵参数化保持正定；这是物理参数约束，不是独立验证正定性的证据。另检查特征值及是否异常。
- 采用NH3/CH3各3H、Cα上1H的两性离子模型。Cα-H 0.98 Å、N-H 0.91 Å、甲基C-H 0.98 Å；NH3和CH3各有一个精修扭转角。H的Uiso分别为母原子Ueq的1.2或1.5倍。
- C/N/O/H散射因子使用 `solve.py` 中显式列出的通用四高斯中性原子系数。无外部散射数据库、无f′/f″、无电荷密度/多极模型。
- 精修最小化 `sum w*(k|Fc|²-I)²`，`w=1/(sigma(I)²+(0.03*max(I,0))²)`。包括所有允许的合并反射及负值，而不是只用I>2σ。I>2σ仅用于报告观测R1。
- 57个参数：18个非氢坐标、36个U参数、1总比例、2氢扭转角。
- 完整参数协方差由雅可比矩阵求得并按残差方差缩放；键长su传播坐标协方差，未加入晶胞su或系统误差。
- 差值Fourier使用实测合并反射，负I的振幅取0，未测系数取0，差值F000取0；网格48×48×96。不是填补的完整实验电子密度。

## 6. 检验与可复现性

`validate_model.py` 检查化学式、原子数、对称群封闭性、解析消光、ADP、短接触、CIF/FCF数值读回、追加精修参数移动以及五折条件强度预测。五折检查共享已求得的取向/手性起点，因此不是完全盲的五次重新求解。代码同时报告数值质量目标，不能把“基本语法检查通过”或“程序退出码0”直接等同于发表质量。

`run_pipeline.py` 在新的交付子目录内从只读原始帧运行全流程，包含重新求解，保存每步stdout/stderr、软件版本、代码SHA-256及用时。严格检查解释器路径，不安装、不联网、不调用其他程序。

另见 `reproducibility_comparison.json`：比较独立重跑与主模型的合并数据、计算振幅，并允许对称、原点、反演和两个氧原子标签的等价变化。允许反演是因为绝对构型确实未知，不能据此把任意坐标手性命名为D或L。
