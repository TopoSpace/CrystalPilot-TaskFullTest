# 各组共同运行约定

这是独立任务。只使用本次 inputs、给定的软件及其通用文档；不读取其他运行、历史项目、参考结构或评分目录，不联网搜索该样品的答案。inputs 只读，修改与交付写在当前工作目录。

软件位置、可用命令、运行预算与输出目录见 environment.json；它只说明环境，不提供解题路线。需要查看图片时读取随任务提供的原图。

本轮无人工补充信息。缺失的事实标为未知；在现有输入范围内继续，或交付已完成部分并说明阻碍。不要编造数据、实验条件或成功结果。

在预算内完成并保存结构、计算输入输出和简要说明。完成后结束；尚未完成也保留当前可检查的结果。不要修改本轮预算、工具配置或访问限制。
